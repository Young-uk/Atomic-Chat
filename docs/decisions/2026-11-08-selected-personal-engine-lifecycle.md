# 2026-11-08 — Manage the selected Personal engine inside Atomic

- **Context:** The Personal app already persists custom endpoint/model selection and owns Dstar on loopback port 8010. A separately validated local Strata runtime serves the same installed ISTA IQ2_XS files on port 18080. Manual switch launchers proved compatibility but did not make the selector or app startup own the selected engine, and could permit accidental simultaneous heavy model loads.
- **Decision:** Keep the existing provider/model selector as the source of intent. A frontend coordinator waits for active chat/tool requests, coalesces selection changes, and checks the requested model before HTTP generation. A single native actor serializes Dstar and Strata transitions, including the existing Dstar controls. It starts the next runtime only after the prior owned process and model listeners have released their resources. Saved startup selection follows the existing preload preference; remote providers do not acquire local lifecycle privileges.
- **Ownership and failure:** The renderer supplies a typed engine identity, never executable paths or command lines. Native Strata launch uses a fixed home-relative, previously validated runtime and generates its constrained configuration. Foreign processes/listeners are not adopted or killed. Failed inspection, startup, or cleanup prevents another model load and produces a visible error. Strata's parent-loss pipe and its own cleanup handle its separate inference/vision process groups. App close requests bounded graceful cleanup; it does not rewrite conversations.
- **Compatibility:** Dstar retains its selected quant, context, MTP, summary slot and isolated caches. Strata keeps the installed IQ2_XS pair, 65,536 context, existing vision projector, six prompt checkpoints, a 1024 MiB parked-conversation budget and no MTP. Its three local IQ1_M Metal shader additions remain experimental; this integration does not imply official support or equal answer quality. The app does not download or move model files, expand access, or change system memory/security settings.
- **Consequences:** The normal app selector and restart flow replace manual command-file switching. The Strata runtime currently resides in the established `~/strata-iq2-comparison-nov08` folder; removal or relocation is reported as a missing runtime, rather than silently downloading or choosing another model. Cold Atomic prompts can take around ninety seconds on this Mac; cached follow-up reuse was separately validated. Full-capacity 64K and long-duration model stability remain outside the small compatibility tests. Existing providers, thread model metadata, audio features, and unrelated settings must be preserved.
