# Use measured personal Strata prompt chunks and memory reserve

- **Context:** the personal 64 GiB M1 Max streams ISTA IQ3_XXS experts from its internal SSD. SSD worker/read-ahead changes did not improve inference. A fixed expert arena bypasses automatic growth checks, so it is unsuitable as a default.
- **Decision:** use `--prefill 4096` together with `STRATA_METAL_PROMPT_CHUNK=4096`. Keep the existing six I/O workers and six read-aheads. Set `STRATA_METAL_KEEP_FREE_GB=8`, reducing the macOS free-memory target from about 10.3 GB to 8 GB. Automatic arena sizing, shrinking and growth checks and the footprint cap remain active. Do not set `STRATA_METAL_ARENA_GB`.
- **Chunk evidence:** 64K context, vision enabled, the same native/backend/model, weighted continuations, fixed 18 GB expert arena, temperature 0, 6465 fresh input tokens and 64 output tokens. Each process received a separate preparation request. Trial orders were 2048/1024/4096 and 4096/1024/2048. Input means were 115.3, 160.7 and 192.7 tokens/s respectively: 4096 improved input throughput about 20% over 2048, and first output time fell from 40.3 to 33.6 seconds. Every setting reused 6458 tokens on the repeated input; cached first output took about 0.25-0.30 seconds. Identical test cases produced identical output hashes. No material output-throughput improvement is attributed to chunk size.
- **Reserve evidence:** separate short trials with automatic sizing and vision enabled used two fresh inputs of about 2150 tokens and 64 output tokens each. Arenas were 20.55 and 22.65 GB with the default reserve and 8 GB reserve. Median input rates were 140.46 and 146.01 tokens/s; post-first-token output estimates were 16.19 and 18.04 tokens/s. These synthetic trials support this personal machine/configuration, not a general hardware or long-context quality claim.
- **Larger-chunk check:** a later 16268-token trial used a fixed 22 GB arena and 12 GiB arena blocks for both candidates, allowing the 8.61 GB scratch area to stay inside the arena. Trial order was 4096/8192/8192/4096. Mean input rates were 208.07 and 195.18 tokens/s; first output took 78.28 and 83.43 seconds. All output hashes matched. The short post-first-token output estimate favored 8192, but total completion time still favored 4096 (83.78 versus 88.36 seconds). Keep 4096; do not ship the experimental arena/block overrides.
- **Compatibility:** update the resolved configuration qualification pin. Admit only the exact reviewed 64K predecessors, retaining native, backend and model checks and the native session reader's validation. The changes affect transient work sizes and weight residency rather than session geometry. Other contexts retain the existing fail-closed compatibility rule.
- **Validation:** the combined configuration must pass qualified inference and an old-session restore before installation, the application regression gate, signed release and startup with the saved user cache. Private trial records remain in the personal task workspace.
- **Owner:** personal fork. Dstar settings are unchanged.
