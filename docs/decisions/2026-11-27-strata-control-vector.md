# Request-scoped Strata control vectors

The Atomic composer shows a control next to tool permissions for the registered local Strata provider. The model endpoint must advertise a loaded vector before the button becomes actionable. Stock is the session default. The transport captures the choice with the provider selection so an in-progress tool continuation keeps its mode.

The personal Metal runtime is qualified separately from the base runtime and serves the same managed endpoint. Stock checkpoints retain the legacy disk identity and existing disk cache. Projected checkpoints use a separate in-memory tag because Stock and projected model states are incompatible. The native engine refuses to persist projected state to the Stock disk cache.
